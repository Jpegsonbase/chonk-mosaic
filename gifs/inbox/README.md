# Drop new animations here

Upload an MP4 to this folder on github.com (Add file → Upload files → Commit changes).

Name it **Title - ChonkNumber.mp4**, e.g. `GM Rainy Street - 61137.mp4` (the number is optional).

A few minutes later it's on chonkit.xyz/gifs with a full-quality MP4 download and the best GIF under 15 MB,
and the upload is cleared from this folder.
